# Recorded declared-scope example

```sh
go run ./examples/scope /tmp/proven-scope-example
```

Open `/tmp/proven-scope-example/scope-review.html`, or inspect its JSON/Markdown siblings. The scenario has a PR declaration, a distinct commit declaration, a reviewer's request and a placeholder comment.

The actual validator checks source excerpts and head-code citations; the actual report writers render the outputs. Model answers are recorded fixtures. There is no live model request, GitHub post, acceptance test or assertion of production accuracy. The displayed repository, comments and code are synthetic.

The [scope walkthrough](../../docs/PR_DELIVERY.md) uses this example for labelled screenshots.
