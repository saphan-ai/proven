# Alerts

The backup tool sends alerts to a team chat. This section tells you which alerts go out, how to set up a chat
destination and how alerts are routed.

- [What goes out](what-goes-out.md): the five alerts and the fields each one carries.
- [Chat setup](chat-setup.md): how to set up a chat destination and where to put the chat credential.
- [Related](related.md): routing, and what happens when an alert cannot be delivered.

## Destinations

Destination ids begin with `c`, for example `chat:c-backup-ops`.
